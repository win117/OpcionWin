# Integraciones externas

Alpaca, Webull y SEC tienen espacios separados para sus adaptadores. No se realizan solicitudes externas en esta etapa. Verificar documentación vigente y permisos antes de implementarlos. La integración no sustituye los algoritmos de los cores. Las operaciones con brokers requieren validación y autorización explícita; eliminar datos locales no cancela órdenes.
